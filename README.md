## Ответы на контрольные вопросы

1. Чем отличается var от let и const?
Переменные var имеют функциональную область видимости и видны во всей функции, даже если объявлены внутри блока. Переменные let имеют блочную область видимости и видны только в пределах объявленного блока.
С переменными var можно взаимодействовать ещё до строки объявления. Переменная let недоступна до строки объявления.
Переменную let можно объявить лишь единожды в пределах одного блока, в отличие от var.
Переменные const остаются неизменными в течении всей программы. Задать значение такой переменной можно только при создании.

2. Что такое неявное преобразование типов в JavaScript?
Это автоматическое преобразование типов данных при выполнении операций. Например, при сравнении строки и числа, программа попытается преобразовать строку в число.

3. Чем отличается == от ===?
== сравнивает значения с приведением типов, то есть в таком случае "5" == 5 будет true, так как несмотря на разный тип, значение одинаковое.
=== сравнивает значения и типы без преобразования, то есть в таком случае "5" === 5 будет false, так как несмотря на одинаковое значение, тип разный.
